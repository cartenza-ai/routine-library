routine_def:
  id: logbook_activity_timeline
  name: "Logbook Activity Timeline"
  version: "1.0"
  description: >
    Generates an interactive day-swimlane HTML timeline of every knowledge-repo
    entry in a package within a given date range — not just milestones. Groups
    entries by calendar day, colors each dot by entry_type, resolves visual
    collisions for closely-timed entries with leader lines back to their true
    timestamp, and shows the full entry on hover. Useful for demo prep, sprint
    retrospectives, or showing the pace/texture of AI-assisted work rather than
    just its headline outcomes.

  variables:
    - name: package
      type: string
      required: true
      description: "Knowledge repo package to pull entries from (e.g. residential_ac)"
    - name: start_date
      type: string
      required: true
      description: "Start of the date range, inclusive, format YYYY-MM-DD"
    - name: end_date
      type: string
      required: true
      description: "End of the date range, inclusive, format YYYY-MM-DD"

  pre_flight:
    - check: "package exists in knowledge_repo"
      on_fail: "abort — ask engineer to confirm package name via list_artifact_packages"
    - check: "start_date <= end_date"
      on_fail: "abort — ask engineer to correct the date range"

  resources:
    - id: kb_source
      type: knowledge_repo
      mcp_tool: browse_knowledge_repo
      note: "Already connected via clone_knowledge_repo — no separate resource fetch needed"
    - id: workspace_output
      type: workspace_manager
      mcp_tool: write_workspace_artifact
      note: "Needed to write the HTML artifact output"

  outputs:
    - name: "Activity Timeline — {{ package }} — {{ start_date }} to {{ end_date }}"
      type: html
      package: "{{ package }}"
      required: true
      bind_as: timeline_artifact

  prompt_template: |
    You are producing an interactive activity-timeline HTML artifact.

    ## Input
    Package: {{ package }}
    Date range (inclusive): {{ start_date }} to {{ end_date }}

    ## Step 1 — Fetch and filter
    Use browse_knowledge_repo on {{ package }} to get every entry (all
    entry_types — note, decision, observation, issue, milestone,
    lesson_learned — not just milestones). Keep only entries whose timestamp
    date falls between {{ start_date }} and {{ end_date }}, inclusive.

    ## Step 2 — Extract per entry
    For each kept entry, record:
    - date: YYYY-MM-DD (UTC)
    - t: HH:MM or HH:MM:SS as given in the timestamp
    - s: seconds since midnight UTC (compute from t)
    - type: the entry_type
    - id: the artifact_id (short form, e.g. note-0007)
    - title: a clean, plain-text title under ~70 chars — strip markdown
      bold/italics markers, paraphrase/truncate at a word boundary with an
      ellipsis if the original title was cut off. Never fabricate detail not
      present in the entry.

    ## Step 3 — Group by day
    Group entries by calendar date. Sort each day's entries chronologically.

    ## Step 4 — Generate the HTML artifact
    Reuse this exact template (CSS, layout, and collision-avoidance JS
    unchanged) — only the DATA array and the H1/subtitle text change per run.
    Do not restyle, rename CSS variables, or alter the day-swimlane / leader-
    line / hover-tooltip mechanics; they're tuned to stay readable at any
    entry density.

    ```html
    <!DOCTYPE html>
    <html lang="en">
    <head>
    <meta charset="UTF-8">
    <title>Activity Timeline</title>
    <style>
      :root {
        --navy: #1E2761; --teal: #028090; --seafoam: #00A896; --mint: #02C39A;
        --coral: #F96167; --gold: #C9971F; --gray: #8A93A6;
        --ink: #14182E; --paper: #FAFBFD; --line: #DCE2ED;
      }
      * { box-sizing: border-box; }
      body { margin: 0; background: var(--paper); font-family: Calibri, Arial, sans-serif; color: var(--ink); padding: 28px 32px 40px; }
      h1 { font-family: Cambria, 'Times New Roman', serif; font-size: 25px; margin: 0 0 3px; color: var(--navy); }
      .subtitle { font-size: 13.5px; color: #5A6378; margin: 0 0 18px; }
      .legend { display: flex; flex-wrap: wrap; gap: 14px 22px; margin-bottom: 20px; padding: 10px 14px; background: white; border: 1px solid var(--line); border-radius: 8px; }
      .legend-item { display: flex; align-items: center; gap: 6px; font-size: 12px; color: #444c5e; }
      .swatch { width: 10px; height: 10px; border-radius: 50%; display: inline-block; flex-shrink: 0; }
      .day-row { display: grid; grid-template-columns: 108px 1fr; align-items: center; border-bottom: 1px solid var(--line); padding: 16px 0; }
      .day-row:last-child { border-bottom: none; }
      .day-name { font-weight: bold; font-size: 14px; color: var(--navy); }
      .day-date { font-size: 11px; color: #6b7386; }
      .day-count { display: inline-block; margin-top: 5px; font-size: 10.5px; font-weight: bold; color: var(--teal); background: #E4F3F3; padding: 1px 7px; border-radius: 10px; }
      svg { overflow: visible; display: block; }
      .baseline { stroke: var(--line); stroke-width: 1.5; }
      .tick { stroke: #B7C0D1; stroke-width: 1.2; }
      .leader { stroke: #C6CDDB; stroke-width: 1; }
      .dot { stroke: white; stroke-width: 1.4; cursor: pointer; }
      .hourlabel { font-size: 9.5px; fill: #9aa2b3; }
      #tooltip { position: fixed; display: none; max-width: 260px; background: var(--navy); color: white; font-size: 12px; line-height: 1.4; padding: 8px 10px; border-radius: 6px; pointer-events: none; z-index: 10; box-shadow: 0 6px 18px rgba(0,0,0,0.25); }
      #tooltip .tt-time { color: var(--mint); font-weight: bold; font-size: 11px; display: block; margin-bottom: 2px; }
      #tooltip .tt-type { color: #AEB8D6; font-size: 10px; text-transform: uppercase; letter-spacing: 0.04em; }
      footer { margin-top: 20px; font-size: 10.5px; color: #9aa2b3; }
    </style>
    </head>
    <body>

    <h1>{{ '{{ TITLE }}' }}</h1>
    <p class="subtitle">{{ '{{ SUBTITLE }}' }}</p>

    <div class="legend" id="legend"></div>
    <div id="days"></div>
    <footer>Each row is scaled to that day's own active window, so tightly-clustered work is spread out for readability. Hover any point for the full entry.</footer>
    <div id="tooltip"></div>

    <script>
    const TYPE_COLOR = { milestone: '#028090', decision: '#1E2761', observation: '#00A896', issue: '#F96167', note: '#8A93A6', lesson_learned: '#C9971F' };
    const TYPE_LABEL = { milestone: 'Milestone', decision: 'Decision', observation: 'Observation', issue: 'Issue', note: 'Note', lesson_learned: 'Lesson Learned' };

    const DATA = [
      /* {{ '{{ INSERT FILTERED, SORTED ENTRY OBJECTS HERE: ' }}
         { d:"YYYY-MM-DD", t:"HH:MM[:SS]", s:<seconds since midnight>, type:"...", id:"...", title:"..." } }} */
    ];

    function fmtDate(d){ const dt=new Date(d+"T00:00:00Z"); return dt.toLocaleDateString('en-US',{month:'short',day:'numeric',timeZone:'UTC'}); }
    function dayName(d){ const dt=new Date(d+"T00:00:00Z"); return dt.toLocaleDateString('en-US',{weekday:'short',timeZone:'UTC'}); }
    function fmtHour(sec){ let h=Math.floor(sec/3600); const suf=h>=12?'PM':'AM'; let h12=h%12; if(h12===0)h12=12; return h12+suf; }

    const days = {}; DATA.forEach(e => { (days[e.d]=days[e.d]||[]).push(e); });
    const dayKeys = Object.keys(days).sort();
    const TRACK_W = 900, MIN_GAP = 30, ROW_H = 64, DOT_R = 6;

    const legendEl = document.getElementById('legend');
    Object.keys(TYPE_LABEL).forEach(k => {
      const item = document.createElement('div'); item.className='legend-item';
      item.innerHTML = `<span class="swatch" style="background:${TYPE_COLOR[k]}"></span>${TYPE_LABEL[k]}`;
      legendEl.appendChild(item);
    });

    const daysEl = document.getElementById('days');
    const tooltip = document.getElementById('tooltip');

    dayKeys.forEach(dk => {
      const entries = days[dk].slice().sort((a,b)=>a.s-b.s);
      const minS = entries[0].s, maxS = entries[entries.length-1].s;
      const pad = Math.max((maxS-minS)*0.08, 300);
      const domainMin = minS-pad, domainMax = maxS+pad;
      const scaleX = s => ((s-domainMin)/(domainMax-domainMin))*TRACK_W;

      let placed = [];
      entries.forEach(e => {
        let x = scaleX(e.s);
        if (placed.length && x - placed[placed.length-1].x < MIN_GAP) x = placed[placed.length-1].x + MIN_GAP;
        placed.push({...e, trueX: scaleX(e.s), x});
      });
      const overflow = placed[placed.length-1].x - TRACK_W;
      if (overflow > 0) placed = placed.map(p => ({...p, x: p.x - overflow}));

      const row = document.createElement('div'); row.className = 'day-row';
      row.innerHTML = `<div class="day-label"><div class="day-name">${dayName(dk)}</div><div class="day-date">${fmtDate(dk)}</div><div class="day-count">${entries.length} ${entries.length===1?'entry':'entries'}</div></div>`;

      const svgNS = 'http://www.w3.org/2000/svg';
      const svg = document.createElementNS(svgNS,'svg');
      svg.setAttribute('width', TRACK_W+20); svg.setAttribute('height', ROW_H);
      svg.setAttribute('viewBox', `0 0 ${TRACK_W+20} ${ROW_H}`);
      const baseY = ROW_H-14, dotY = 20;

      const baseline = document.createElementNS(svgNS,'line');
      baseline.setAttribute('class','baseline'); baseline.setAttribute('x1',0); baseline.setAttribute('x2',TRACK_W);
      baseline.setAttribute('y1',baseY); baseline.setAttribute('y2',baseY); svg.appendChild(baseline);

      for (let i=0;i<=4;i++){
        const s = domainMin + (i/4)*(domainMax-domainMin);
        const x = (s-domainMin)/(domainMax-domainMin)*TRACK_W;
        const tick = document.createElementNS(svgNS,'line'); tick.setAttribute('class','tick');
        tick.setAttribute('x1',x); tick.setAttribute('x2',x); tick.setAttribute('y1',baseY-3); tick.setAttribute('y2',baseY+3);
        svg.appendChild(tick);
        const label = document.createElementNS(svgNS,'text'); label.setAttribute('class','hourlabel');
        label.setAttribute('x',x); label.setAttribute('y',baseY+14); label.setAttribute('text-anchor','middle');
        label.textContent = fmtHour(((s%86400)+86400)%86400); svg.appendChild(label);
      }

      placed.forEach(p => {
        const leader = document.createElementNS(svgNS,'line'); leader.setAttribute('class','leader');
        leader.setAttribute('x1',p.trueX); leader.setAttribute('x2',p.x); leader.setAttribute('y1',baseY); leader.setAttribute('y2',dotY+DOT_R);
        svg.appendChild(leader);
        const tickMark = document.createElementNS(svgNS,'line'); tickMark.setAttribute('class','tick');
        tickMark.setAttribute('x1',p.trueX); tickMark.setAttribute('x2',p.trueX); tickMark.setAttribute('y1',baseY-3); tickMark.setAttribute('y2',baseY+3);
        svg.appendChild(tickMark);
        const dot = document.createElementNS(svgNS,'circle'); dot.setAttribute('class','dot');
        dot.setAttribute('cx',p.x); dot.setAttribute('cy',dotY); dot.setAttribute('r',DOT_R); dot.setAttribute('fill',TYPE_COLOR[p.type]);
        dot.addEventListener('mousemove', (ev) => {
          tooltip.style.display='block'; tooltip.style.left=(ev.clientX+14)+'px'; tooltip.style.top=(ev.clientY+14)+'px';
          tooltip.innerHTML = `<span class="tt-time">${p.t} UTC</span><span class="tt-type">${TYPE_LABEL[p.type]} &middot; ${p.id}</span><div style="margin-top:4px">${p.title}</div>`;
        });
        dot.addEventListener('mouseleave', () => { tooltip.style.display='none'; });
        svg.appendChild(dot);
      });

      row.appendChild(svg); daysEl.appendChild(row);
    });
    </script>
    </body>
    </html>
    ```

    Replace `{{ '{{ TITLE }}' }}` with a short, context-appropriate title (e.g.
    "{{ package }} — Engineering Activity Timeline") and `{{ '{{ SUBTITLE }}' }}`
    with "Every logged entry, {{ start_date }} – {{ end_date }} · not just
    milestones". Fill the DATA array with the entries from Step 2, one object
    per line, comma-separated, in the exact field order shown.

    ## Step 5 — Store and log
    1. write_workspace_artifact: type "html", name "Activity Timeline —
       {{ package }} — {{ start_date }} to {{ end_date }}", package
       "{{ package }}".
    2. push_artifacts (workspace-manager).
    3. add_log_entry (knowledge-repo, package {{ package }}, entry_type
       "note") referencing the new artifact_id, noting the date range and
       entry count.
    4. push_artifacts (knowledge-repo).
    5. generate_viewer_link and return it.
